## How are decisions, information, and databases connected?
* Good decisions are made because of good information.
* Good information is drawn from raw facts. 
* Efficient data management occurs when data is stored in a database.
* Databases evolved from earlier computer file systems.

## What is the difference between data and information, and why is it crucial?
* Data consists of raw facts.
* We need to process these raw facts into information. 
* The meaning of the information is revealed when we add context to the information. 
* Raw facts need to be formatted for storage, presentation, and processing. 
### what is the key to good decision making?
* The key to good decision-making is accurate, relevant, and timely information.
* The key to organizational survival is good decision-making.

## What is a database and what exactly does it store?
* Databases are shared, integrated computer structures which are used to store collections of data.
* They store **end-user data** (raw facts of interest to the user) and **metadata**.
* Metadata provides descriptions of the characteristics of the data and the relationships between them.
* Metadata expands the value of the data and is known as "data about data."

---

## What are the different types of databases and how are they classified?
* The type of database depends on the number of users, the database location, the database use-case, and the degree to which the data is structured.
* **By Number of Users:** We can get single-user databases which support only one user at a time, or multi-user databases which support multiple users at a time. Multi-user databases include workgroups (small numbers) and enterprises.
* **By Location:** A database could be centralized (data is stored at a single site) or distributed (data is distributed across multiple sites).
* **By Use-Case:** There are operational databases for day-to-day operations and data warehouses used to store data for strategic decisions.
* **By Structure:** Unstructured databases store data in its original state, structured databases have formatting which has been applied, and semi-structured databases have data which has been processed to some extent.

---

## How is data organized within a file system?
* File systems are organized into data, fields, records, and files. 
* **Data:** The raw facts.
* **Fields:** Define the data and have a specific meaning.
* **Records:** A logically connected set of fields that describes something.
* **Files:** Collections of related records.

---

## What are the main problems associated with file management systems?
* The issues mainly boil down to data redundancy, data inconsistency, and data anomalies.
* **Data redundancy:** Occurs when the same data is stored in different places unnecessarily. 
* **Data inconsistency:** Occurs when conflicting versions of the same data occur at different locations.
* **Data anomalies:** Occur when not all the changes are updated correctly to all the redundant data.

---

## How can we summarize the core concepts and benefits of databases?
* Data is raw facts, and information is the result of processing that data to reveal its meaning. 
* The key to good decision-making is accurate, relevant, and timely information.
* Metadata is the data about the data.
* Databases are used to store data and they solve the issues inherent in file management systems.
* Databases promote data sharing, prevent islands of information, and create a single version of "truth" of the data (consistency).
